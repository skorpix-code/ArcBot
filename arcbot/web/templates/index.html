          Set up ArcBot

          Four choices. You can change any of them later.

            Choose a brain

            ArcBot does not ship a model. Point it at one you already have access to — a local one, an API key, or your Claude subscription.

              Pick a workspace

              This folder is the agent's world. File tools cannot read or write outside it, and commands start here. Pick a project folder, or make a scratch one.

              What lives here A hidden .arcbot folder holds this workspace's memory, plan and chat transcripts. Nothing leaves your machine.

              Set the trust level

              How much should ArcBot do without asking? Every command is graded by risk; this decides where the line for approval sits.

              Turn on what you need

              Only what you enable gets loaded. If a task later needs something switched off, ArcBot asks you to enable it with one click instead of failing.
